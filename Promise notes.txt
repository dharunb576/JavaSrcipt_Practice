Usage of Async:
    The general flow of program shouldn't
affect by the piece of heavy load of code.
So it can be written inside the async.

Promise:
    it is one of the way of writing like 
async function.

->Pending --- loading 
->Resolve --- completed
->Reject --- error occur

Example program:

const data = new Promise((resolve,reject)=>{

    setTimeout(()=>{
        const ans = "antio"
        if(ans){
            resolve(ans)
        }
        else{
            reject("No data")
        }
    },2000)
})

data
    .then((name)=>{
    console.log(name)
})
    .catch((error)=>{
        console.log(error)
    })
    .finally(()=>{
        console.log("The Final State")
    })
